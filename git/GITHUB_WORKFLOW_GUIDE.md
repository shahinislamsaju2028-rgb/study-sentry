# GitHub/Git ওয়ার্কফ্লো কিট — নতুন আইডিতে ২-৩ মিনিটে কাজ শুরু

> **সমস্যা:** ড্রাইভে জিপ আপলোড → নতুন এজেন্ট ৩০-৪০ মিনিট ডাউনলোড/এক্সট্র্যাক্ট/পুরো প্রজেক্ট ঘাটায় খরচ করে → বারবার একই কাজ।
>
> **সমাধান:** প্রজেক্ট থাকবে একটাই জায়গায় — GitHub-এর প্রাইভেট রিপোতে। যে এজেন্ট-ই হোক, `git clone` করে মিনিটের মধ্যে কাজে নেমে যাবে, আর `HANDOFF.md` পড়লেই পুরো প্রজেক্টের "গল্প" বুঝে ফেলবে — কোনো জিপ, কোনো ড্রাইভ ডাউনলোড লাগবে না।

## এই কিটে যা আছে

| ফাইল | কাজ |
|---|---|
| `GITHUB_WORKFLOW_GUIDE.md` | এই গাইড (প্রজেক্টেও রেখে দিন, পরে লাগবে) |
| `HANDOFF.md` | প্রজেক্ট রুটে রাখা "হ্যান্ডঅফ নোট" — নতুন এজেন্ট এটাই পড়ে শুরু করে |
| `git-init-repo.ps1` | একবার চালালেই প্রজেক্ট ফোল্ডারকে git রিপোতে রূপান্তর + GitHub-এ push |
| `sync.ps1` | প্রতিদিনের এক-কমান্ড pull / commit / push (আপনার Windows মেশিন থেকে) |

## কেন এত দ্রুত হবে

- **আগে:** পুরো জিপ ড্রাইভ থেকে নামানো, এক্সট্র্যাক্ট, তারপর নতুন করে পুরো কোডবেস পড়ে কনটেক্সট তৈরি — এতেই ৩০-৪০ মিনিট।
- **এখন:** ছোট রিপো থেকে সেকেন্ডে clone → `HANDOFF.md` (এক-দুই পাতা) → সরাসরি কাজ। শুধু পরিবর্তিত ফাইল আসে-যায়; বড় ফোল্ডার (`node_modules`, `target`, `dist`) কখনো যায় না।
- পুরো ইতিহাস থাকে: কে কখন কী বদলেছে, ভুল হলে এক কমান্ডে ফেরানো যায়।
- প্রতিটা push = ফ্রি ব্যাকআপ।

## ধাপ ০ — প্রয়োজনীয় জিনিস (একবার)

1. **GitHub অ্যাকাউন্ট** — না থাকলে https://github.com/signup এ ফ্রি অ্যাকাউন্ট খুলুন।
2. **Git (Windows)** — ইনস্টল না থাকলে https://git-scm.com/download/win । ইনস্টলের সময় ডিফল্ট অপশনই চলবে; সম্ভব হলে "Git from the command line and also from 3rd-party software" বাছুন।
3. **এই কিটের ফাইলগুলো** — কপি করে আপনার প্রজেক্ট রুটে বসান:
   ```
   Downloads\Study-Sentry-Source-v4.0.0\study-sentry\
   ```
   ভেতরে যাবে: `HANDOFF.md`, `git-init-repo.ps1`, `sync.ps1`, `GITHUB_WORKFLOW_GUIDE.md`

## ধাপ ১ — একবার: রিপো তৈরি ও প্রথম push (১০ মিনিট)

1. **Win+X → Terminal (PowerShell)** খুলুন, প্রজেক্ট ফোল্ডারে যান:
   ```powershell
   cd $env:USERPROFILE\Downloads\Study-Sentry-Source-v4.0.0\study-sentry
   ```
2. স্ক্রিপ্ট চালান:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\git-init-repo.ps1 -RepoName study-sentry
   ```
3. এরপর দুইটা পরিস্থিতি:
   - **`gh` CLI ইনস্টল থাকলে** — স্ক্রিপ্ট নিজেই GitHub-এ প্রাইভেট রিপো বানিয়ে push করে দেবে (প্রথমবার GitHub লগইন চাইতে পারে)।
   - **না থাকলে** — স্ক্রিনে প্রিন্ট হওয়া নির্দেশনা মেনে:
     1. https://github.com/new খুলুন → নাম: `study-sentry` → **Private** সিলেক্ট → "Add a README" বন্ধ রাখুন → **Create repository**।
     2. ফিরে টার্মিনালে (ইউজারনেম বসিয়ে):
        ```powershell
        git remote add origin https://github.com/<আপনার-ইউজারনেম>/study-sentry.git
        git push -u origin main
        ```
     3. প্রথম push-এ ব্রাউজার খুলে GitHub লগইন চাইবে — একবার লগইন করলেই ক্রেডেনশিয়াল সেভ থাকবে।
4. **ভেরিফাই:** ব্রাউজারে `https://github.com/<ইউজারনেম>/study-sentry` খুলে ফাইলগুলো দেখুন। এরপর ড্রাইভের জিপ আর দরকার নেই (ব্যাকআপ হিসেবে একটা রেখে দিতে পারেন)।

## ধাপ ২ — প্রতিদিনের ফ্লো

### ক) পুরোনো সেশন শেষ করার আগে (লিমিট শেষ হওয়ার আগে!) — এজেন্টকে এই প্রম্পট পেস্ট করুন

```
কাজ এখানে থামাও, সেশন শেষ হওয়ার আগে ৩টা কাজ করে দাও:
১. HANDOFF.md আপডেট করো — কী কী হলো (তারিখসহ), গুরুত্বপূর্ণ ফাইল কোথায়, জানা সমস্যা, পরের ধাপ।
২. git add -A && git commit -m "<আজকের কাজের সংক্ষিপ্ত বর্ণনা>" && git push
৩. এরপর থেকে প্রতিটা বড় milestone শেষেই এভাবেই push করে দাও — শেষের জন্য জমিয়ে রাখো না।
```

> এই অভ্যাসটাই আসল নিরাপত্তা জাল: usage limit যে যেকোনো মুহূর্তে শেষ হলেও কাজ হারাবে না — প্রতিটা কমিট আগে থেকেই GitHub-এ জমা আছে।

### খ) নতুন আইডি/সেশন শুরু — নতুন এজেন্টকে এই প্রম্পট দিয়ে শুরু করুন

```
আমার প্রজেক্টের রিপো: https://github.com/<ইউজারনেম>/study-sentry.git
এভাবে শুরু করো:
১. git clone <রিপো URL>   (প্রাইভেট হলে আমি টোকেন দিয়ে দেব)
২. পুরো প্রজেক্ট ঘাটো না। প্রথমে শুধু HANDOFF.md পড়ো + git log --oneline -10 দেখো।
৩. HANDOFF.md-তে তালিকাভুক্ত ফাইলগুলো দেখে সরাসরি কাজ শুরু করো।
```

### ব) আপনার Windows মেশিন থেকে পরিবর্তন আনা/পাঠানো

```powershell
.\sync.ps1 -Message "বাংলা লগইন বাগ ফিক্স"   # pull + commit + push একসাথে
.\sync.ps1                                     # শুধু GitHub থেকে সর্বশেষ আনবে
```

## ধাপ ৩ — প্রাইভেট রিপোর ক্লোন-অ্যাক্সেস (নতুন এজেন্টের জন্য)

স্যান্ডবক্সে ব্রাউজার লগইন হয় না, তাই প্রাইভেট রিপো ক্লোন করতে **টোকেন** লাগবে (এক সেশনে একবার দিলেই হয়):

1. https://github.com/settings/personal-access-tokens/new (Fine-grained token) এ যান →
   - **Repository access → Only select repositories → study-sentry**
   - **Permissions → Contents → Read and write**
   - Expiration যেমন ৭ দিন → **Generate token**
2. নতুন এজেন্টকে প্রম্পটসহ টোকেনটা দিন; সে ক্লোন করবে:
   ```bash
   git clone https://<TOKEN>@github.com/<ইউজারনেম>/study-sentry.git
   ```
3. **সতর্কতা:** টোকেন কখনো কোনো ফাইলে বা কমিটে বসাবেন না। সন্দেহ হলে https://github.com/settings/tokens থেকে এক ক্লিকে revoke করে নতুনটা বানিয়ে নিন।

- কোড বিশেষভাবে গোপনীয় না হলে **Public রিপো** সবচেয়ে সহজ — তখন টোকেনের দরকারই নেই, যে এজেন্ট তৎক্ষণাৎ clone করতে পারবে।

## ট্রাবলশুটিং

- **push rejected / `non-fast-forward`** → আগে `git pull --rebase`, তারপর আবার `git push`। কনফ্লিক্ট হলে এজেন্টকে বলুন "git কনফ্লিক্ট resolve করে push করো।"
- **commit বলে `Please tell me who you are`** → চালান:
  ```powershell
  git config --global user.name "আপনার নাম"
  git config --global user.email "you@example.com"
  ```
- **কোনো ১০০ MB+ ফাইল push reject করলে** (ইনস্টলার, ভিডিও ইত্যাদি) → সেটা `.gitignore`-এ দিন; রিপোতে রাখার দরকার নেই।
- **এজেন্ট commit/push ভুলে গেলে** → সেশন শেষের প্রম্পটটা (ধাপ ২-ক) মনে করিয়ে দিন।
- **`.gitignore`** আপডেট দরকার হলে `git-init-repo.ps1` আবার চালাতে পারেন — এটা শুধু অনুপস্থি এন্ট্রি যোগ করে, আগেরটা মুছে না।

## পুরনো অভ্যাসের সাথে তুলনা

| | ড্রাইভ + জিপ (আগে) | GitHub + git (এখন) |
|---|---|---|
| নতুন সেশনে প্রস্তুতি | ৩০-৪০ মিনিট | ২-৩ মিনিট |
| আপলোড/ডাউনলোড | পুরো জিপ বারবার | শুধু পরিবর্তিত ফাইল |
| ভুল ফেরানো | প্রায় অসম্ভব | `git revert` এক কমান্ড |
| ব্যাকআপ | ম্যানুয়াল | প্রতিটা push = ব্যাকআপ |
| দুই মেশিন/এজেন্ট মিলে কাজ | হাতে ফাইল ঘুরানো | pull/push অটো |

প্রথমবার সেটআপে কোথাও আটকালে টার্মিনালের স্ক্রিনশট আমাকে দেখান — বসিয়ে দেবো। চাইলে এই সেশনেই আপনার প্রজেক্ট (ড্রাইভ/জিপ থেকে এনে) আমি রিপোতে push করে দিতে পারি — শুধু রিপো URL + টোকেন দিলে হবে।
